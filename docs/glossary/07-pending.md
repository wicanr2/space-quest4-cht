## 修法：改在建構期的收斂表

**不要直接改譯文檔。** 那些檔多半是從 skeleton + 翻譯批次重新產生的，直接改下次重跑就被蓋掉。

各專案的做法是在 `translation/converge.tsv` 加一行「錯誤寫法 ⇥ 正確寫法」，建構時全域替換。例如：

```
# Kerona：SQ4 作「柯羅娜」，SQ3 原作「克羅納」
克羅納	柯羅娜
```

改完要：

1. 重跑建構（重烘字型與 runtime 表）
2. 同步到 `dist-cht/`
3. **重打所有包**——包是快照、不會回溯。改了 `dist-cht/` 而沒重打，包裡就還是舊譯名，而檔案「存在」看不出這件事
4. 驗收比對包內與 `dist-cht/` 的 md5
