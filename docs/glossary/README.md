# 《宇宙傳奇》系列繁體中文譯名對照表

跨《宇宙傳奇II》《宇宙傳奇III》《宇宙傳奇IV》三代中文化專案整理的專有名詞總表。玩家照系列順序玩下來，同一個角色、同一顆星球必須是同一個中文名，否則會誤以為是兩個不同的東西——這份表就是為了守住這件事。

同時也是後續作品（《宇宙傳奇I》中文化）的譯名依據。

## 基準規則

**[HARD] 以《宇宙傳奇IV》繁中版為基準。** 兩代譯法衝突時一律採四代，不論哪個「比較好聽」。

理由是系列銜接的可預測性：四代是系列中登場人事物最多的一作（前三代的角色、星球、梗都會回頭客串），拿它當錨點，衝突面最小。已依此裁決過的例子：

- **Xenon**：三代原作「澤農」，二代與四代作「氙星」 → 統一「氙星」
- **Kerona**：三代原作「克羅納」，四代作「柯羅娜」 → 統一「柯羅娜」
- **Orat**：三代原作「歐拉獸」，四代作「歐拉特」 → 統一「歐拉特」
- **Buckazoid**：二代原作音譯「巴克佐幣」，三代四代都作「太空幣」 → 統一「太空幣」

四代沒有出現的詞，就取「出現次數多的那個」或「劇情上該詞真正登場的那一作」的譯法。例如 Labion Terror Beast 四代沒有，取二代（怪獸實際登場那一作）的「恐懼獸」。

1988 年軟體世界代理的中文說明書另有一套譯名（羅傑維可、塞倫人、拉賓星球…），**本系列不沿用**，純粹是系列一致性的考量，不是當年翻得不好。

## 表格怎麼讀

每個詞列出它在哪幾代出現過。`✓` 表示該作的譯文表裡確實有這個詞。

| 記號 | 意思 |
|---|---|
| ✓ | 該作出現且用此譯名 |
| — | 該作未出現 |
| ⚠ | 該作用了不同譯名（詳見[尚未對齊](07-pending.md)） |

## 怎麼維護

**譯名漂移要修在建構期的全域收斂表，不要事後手改譯文檔。** 各專案的譯文檔多半是從 skeleton + 翻譯批次合併重新產生的，直接改下次重跑就被蓋掉。三代專案的做法是 `translation/converge.tsv`：一行一組「錯誤寫法 ⇥ 正確寫法」，建構時對所有譯文做全域替換。

批次是平行翻的，同一個專有名詞在不同批各自音譯很正常——收斂表才是治本的地方。

**收工前跑一次跨代比對。** 對每個英文詞撈出各專案的譯句、數各種中文寫法出現幾次，只數不猜。

**[雷] 詞表要涵蓋系列全作的專有名詞，不能只照當前這一作的劇情列。** 2026-07-30 那次稽核就漏了 Kerona 與 Orat——它們是**一代**的名詞，在三、四代只出現在回憶和食物梗裡，照三四代劇情列詞表就會漏掉。

## 跟 `translation/GLOSSARY.md` 的分工

本 repo 另有一份 [`translation/GLOSSARY.md`](../../translation/GLOSSARY.md)，兩者用途不同，別搞混：

| | 這份（`docs/glossary/`） | `translation/GLOSSARY.md` |
|---|---|---|
| 範圍 | **跨三代**的系列總表 | **本作**的翻譯作業表 |
| 讀者 | 想查系列譯名的人、下一款的中文化專案 | 四代的翻譯 subagent |
| 內容 | 各詞在哪幾代出現、為何這樣定、還有哪些沒對齊 | 逐字照用的清單 ＋ 四代專屬名詞 |
| 更新時機 | 跨代稽核後 | 四代翻譯期間發現新詞時 |

兩份衝突時**以這份為準**，並回頭修正作業表。
