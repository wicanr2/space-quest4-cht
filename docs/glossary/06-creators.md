## 片尾工作人員名單的處理原則

**主創者譯名 + 原文並列，其餘保留原文。**

系列三代的實際做法不完全一致，但收斂後的原則是：

1. **玩家會在對白裡遇到的名字**（Scott Murphy、Mark Crowe——他們在遊戲裡是角色，二代還有「我認識的人裡只有馬克·克羅會幹這種事」這種吐槽）**要翻**，並在首次出現時附原文。
2. **純片尾名單**（程式設計、美術、音樂、測試的一長串人名）**保留英文原文**。理由是：這些是真實人名，音譯沒有公認寫法，翻了反而讓想查資料的玩家找不到人；而且名單長，中英夾雜比全部音譯好讀。
3. **配音員與角色的對應**（`GARY OWENS - Narrator`）**角色翻、人名不翻**：`GARY OWENS──旁白`。

四代的片尾就是照這個做的：

> 配音：GARY OWENS──旁白　JEFF BENDER──羅傑·威爾科　STUART MOULDER──小羅傑　BARRY SMITH──單色小子、酒吧外星顧客　KELLI SPURGEON──桑德拉

## 致敬與惡搞的處理

系列大量惡搞當代科幻與流行文化。**梗要翻出來，但不要加註解。**

| 原文的梗 | 處理 |
|---|---|
| `Aluminum Mallard` ← 千年鷹號 | 照字面「鋁製野鴨號」，落差感自然成立 |
| `Cluck Egger` ← 試飛員 Chuck Yeager | 「克拉克蛋哥」，保諧音也保雞的意象 |
| `Droids-B-Us` ← Toys "R" Us | 「機器人量販店」，取功能不取音 |
| `Monolith Burger` ← 麥當勞＋2001太空漫遊 | 「巨石漢堡」，兩個意象都在 |
| `Sir Graham` ← 自家《國王密使》主角 | 「葛拉罕爵士」，跨系列客串照 Sierra 慣例音譯 |

**不要在譯文裡加「（此處惡搞某某）」。** 玩家看得懂就笑，看不懂也不影響理解——加註解會把笑點講死，而且破壞對話框排版。考據要寫的話，寫在 README 或本表，不要寫進遊戲。
